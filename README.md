# 운동 기록장 (웹 앱)

스톱워치로 하루 운동 시간을 기록하고, 월 달력과 기간별 막대그래프로 보는 웹 앱입니다. GitHub Pages에 올린 뒤 iPhone Safari에서 홈 화면에 추가해 사용합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면·기능) |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘 정보 |
| `sw.js` | 인터넷 없이도 열리게 하는 오프라인 저장 |
| `icons/` | 앱 아이콘 |

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `workout-log` (Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 `icons` 폴더를 통째로 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source는 **Deploy from a branch**, Branch는 **main / (root)**로 정하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://hyunkylee.github.io/workout-log/` 주소로 열립니다.

## iPhone에 설치

1. Safari로 위 주소를 엽니다. Chrome에서는 홈 화면 앱으로 설치되지 않습니다.
2. 하단 **공유** 버튼 → **홈 화면에 추가** → **추가**를 누릅니다.
3. 이후에는 홈 화면의 **운동 기록장** 아이콘으로 실행합니다. 주소창 없이 앱처럼 열립니다.

## 기능

| 탭 | 내용 |
|---|---|
| 기록 | 기본 운동 **헬스장**으로 바로 **운동 시작** → **종료하고 저장**하면 시간이 자동 기록됩니다. 다른 운동은 '운동 종류 변경'으로 고릅니다. 앱을 닫아도 계속 잽니다. 지난 운동은 날짜·시작·종료 시각을 입력해 저장합니다(자정을 넘기면 다음 날 종료로 계산). |
| 달력·그래프 | 월간 달력(날짜별 운동 시간 색 단계, 날짜를 누르면 상세 보기), 고른 기간만 보여 주는 막대그래프(최근 7일·30일·이번 달·3개월·직접 선택. 31일 이하는 일별, 26주 이하는 주별, 그 이상은 월별), 합계·하루 평균·종류별 비율, 데이터 백업·복원. |

## 주의

- 기록은 그 iPhone 안에만 저장됩니다. **데이터 백업** 버튼으로 가끔 백업 파일을 만들어 파일 앱이나 iCloud Drive에 저장해 두세요.
- Safari 설정에서 '방문 기록 및 웹사이트 데이터 지우기'를 하면 기록이 지워질 수 있습니다.
- 알람 기능은 없습니다. iPhone의 웹 앱은 닫혀 있을 때 알림을 예약할 수 없습니다.
- `index.html`을 고쳐 다시 올릴 때는 `sw.js`의 `VERSION` 값(예: `v1` → `v2`)도 바꿔 주세요. 그래야 휴대폰에 새 버전이 반영됩니다.
